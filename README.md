# Exercícios de PHP 🐘

Este repositório foi criado para armazenar meus estudos e resoluções de desafios práticos em PHP. O objetivo é consolidar conhecimentos em lógica de programação, manipulação de dados e desenvolvimento web back-end.

## 🚀 O que tem aqui?

O repositório contém resoluções de desafios técnicos e pequenos projetos, como:
* **Desafios de Lógica:** Resolução de problemas matemáticos e condicionais (`desafio2.php`, `desafio3.php`).
* **E-commerce Básico:** Estruturação inicial de um sistema de vendas (`e-commerce.php`).
* **Sintaxe e Tipagem:** Prática de manipulação de variáveis, strings e arrays.

## 🛠️ Tecnologias Utilizadas
* PHP 8.x
* Git & GitHub (Versionamento)
